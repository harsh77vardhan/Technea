# Technea

## Project Description

Technea is an AI-powered learning platform that helps users learn any skill through structured roadmaps, resources, projects, and career guidance.

It is especially designed for beginners, helping them go from scratch to a strong foundation in their chosen skill.


## Problem Statement

Many beginners don't know:

- What to learn first
- Which resources are reliable
- How to progress from beginner level to a good skill level


## Target Users

- Students
- Beginners learning technology skills
- People switching careers


## MVP Features (Version 1)

1. Landing page
2. Skill search
3. Skill roadmap display
4. Learning resources section
5. Project recommendations


## Future Features

- AI personalized roadmap
- User accounts
- Progress tracking
- AI quizzes
- Community
- connecting with friends
- competing with others
