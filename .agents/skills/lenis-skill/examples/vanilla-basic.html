Lenis Smooth Scroll

A lightweight, robust, performant smooth scroll library by darkroom.engineering running on native browser physics.

Hardware Alignment

Runs smoothly at 120Hz/60Hz display refresh rates, supporting anchor scrolling, nested containers, and WebGL / GSAP sync.

Complete Control

Listen to scroll progress, programmatic scrollTo with custom easing curves, and instant lock/release for modal dialogs.
